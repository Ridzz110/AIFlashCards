# 🧠 AI Flash Cards

Welcome to **AI Flash Cards** – a powerful and modern web app that allows users to generate, save, and manage intelligent flashcards powered by AI. Designed to help students, educators, and lifelong learners retain knowledge better and faster.

🔗 Live Site: [ai-flash-cards-gray.vercel.app](https://ai-flash-cards-gray.vercel.app/)

---

## ✨ Features

- 🚀 **Next.js 13 App Router** – App built with dynamic routing and the latest Next.js features.
- 🎨 **shadcn/ui** – Beautiful and accessible UI components.
- 🤖 **Groq API Integration** – AI-generated flashcards based on any input topic or content.
- 🔐 **Clerk Authentication** – Seamless sign-up, login, and user session management.
- 📦 **Firebase Firestore** – Real-time database to store flashcard stacks per user.
- 💳 **Stripe Payments** – Monetization via Stripe with subscription-based access to premium features.
- 💡 **Dynamic Flashcard UX** – Hover to flip, click to save, view, and review cards easily.
- 📂 **Stack Management** – Users can view and manage their personal flashcard stacks.
- 🌐 **SEO Optimized** – Clean URLs, metadata, and performance optimization.

| Tech       | Usage                                |
